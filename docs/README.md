# Project Docs

RelayGraph is a local web dashboard for GPU labs and workflow operations. It combines cluster monitoring, remote command execution, file transfer, browser terminals, and a workspace cockpit for turning repos, papers, and ideas into executable Agent + Job workflows.

Use this directory for long-lived documentation:

- [Features](features.md) - complete product surface and user-facing capability map.
- [Architecture](architecture.md) - current runtime model, module boundaries, and UI split.
- [Development Guide](development-guide.md) - setup, code map, contribution workflow, and quality bar for maintainers.
- [Development Stage](development-stage.md) - current architecture optimization scope, completed cleanup, and next handoff.
- [Review Status](review-status.md) - latest committed review conclusion, fixed issues, and open follow-ups.
- [Testing](testing.md) - committed regression suite and local-only smoke boundary.
- [Development Roadmap](development-roadmap.md) - the next feature phase after the current architecture cleanup.

Official docs are meant to describe committed behavior and stable project direction. Local development notes, one-off smoke scripts, and investigation reports belong in ignored `dev_work/`.

For install, quick start, and config basics, see the top-level [README](../README.md).
